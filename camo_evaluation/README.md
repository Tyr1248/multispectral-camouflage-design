# Camouflage Evaluation

MATLAB toolbox for quantitative evaluation of camouflage effectiveness, combining visual saliency analysis with image quality metrics (SSIM, PSNR) and a Comprehensive Camouflage Evaluation (CCE) framework.

## Contents

| File | Description |
|---|---|
| `CCE/` | Camouflage Comprehensive Evaluation — implementation based on Li et al. (2025) |
| `saliency_cal.m` | Region-based saliency statistics on pre-computed saliency maps |
| `compute_avg_ssim_psnr.m` | Batch SSIM/PSNR evaluation against reference images |
| `replace_squares.m` | Patch replacement for digital camouflage A/B testing |
| `batch_crop_white_borders.m` | Batch white-border cropping |
| `cut_sample.m` | Sample cutting utility |
| `Mark_with_redbound.m` | Mark evaluation regions with bounding boxes |
| `solid_color.m` | Solid color baseline generation |

## Dependencies

### GBVS (Graph-Based Visual Saliency)

The saliency evaluation workflow uses pre-computed saliency maps generated by the GBVS algorithm. To obtain the GBVS MATLAB source code:

- **Download:** [http://www.klab.caltech.edu/~harel/share/gbvs.php](http://www.klab.caltech.edu/~harel/share/gbvs.php)
- **Reference:** J. Harel, C. Koch, and P. Perona. "Graph-Based Visual Saliency." *Advances in Neural Information Processing Systems (NIPS)*, 19:545–552, 2006.

After downloading, add the GBVS directory to your MATLAB path:

```matlab
cd gbvs
gbvs_install
```

### CCE Reference

Y. Li, C. Jia, J. Lv, X. Qing, W. Duan, J. Zhang, and X. Weng. "Evaluation method of camouflage effect based on image feature similarity/fusion degree." *Optics & Laser Technology*, 189:113152, 2025. DOI: [10.1016/j.optlastec.2025.113152](https://doi.org/10.1016/j.optlastec.2025.113152)
